# Glowriva Glow 

### Skincare and Makeup E-Commerce Platform Live Demo : https://glowriva-glow-makeup-website-sq2k.vercel.app

Glowriva Glow is a full-stack skincare e-commerce platform built with the MERN stack. The platform provides a smooth shopping experience with secure authentication, product management, cart functionality and an AI-powered chatbot that helps users with skincare-related queries and personalized product suggestions.

##  Features

### 👤 User Features

* User registration and login system
* JWT-based secure authentication
* Browse skincare products with detailed information
* Search and explore products easily
* Add products to cart
* Update product quantity and remove items from cart
* Responsive and user-friendly interface

###  Product Management

* Display skincare products with images and details
* Product categorization
* Product information management
* Image upload functionality for products
* Dynamic product listing system

### Cart System

* Add products to cart
* View cart items
* Increase/decrease product quantity
* Remove products from cart
* Calculate total price dynamically

### AI Chatbot Assistant

* Answer skincare product-related questions
* Provide skincare advice
* Suggest products based on skin type
* Provide information about offers and discounts
* Answer shipping and delivery-related queries

### 🔐 Authentication & Security

* Secure user authentication using JWT
* Protected routes
* Role-based access for admin functionality

### 👨‍💼 Admin Features

* Admin registration and authentication
* Add new skincare products
* Update existing products
* Delete products
* Manage product information and inventory
